 Sign Text Message

                        
A quick walkthrough: type a message, watch it get signed as Bob and checked as Alice.

                    

                    

                        

                            
                            
                        

                        
                        
                        
                        

                            

                                

                                    

                                        
                                    

                                    
Bob (Sender) - Signing Process

                                

                                

                                    

                                        1. Original Message
                                        

                                    

                                    

                                        2. SHA-256 Hash
                                        
                                    

                                    

                                        3. Digital Signature (RSA Encrypted Hash)
                                        
                                    

                                

                            

                            
                            

                                
                                Message + Signature sent to Alice
                            

                            
                            

                                

                                    

                                        
                                    

                                    
Alice (Receiver) - Verification Process

                                

                                

                                    

                                        1. Received Message Hash
                                        
                                    

                                    

                                        2. Decrypted Signature (Using Public Key)
                                        
                                    

                                    

                                        3. Verification Result
                                        

                                            
                                            Hashes match! Message is authentic.
